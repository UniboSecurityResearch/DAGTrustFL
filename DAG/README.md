# DAG
Repository of the DAG architecture for enabling trust in Federated Learning. 
## DAG SIMULATION

## Folders
**.env** contains the virtual env for Python

**frames** is used for generating the GIF of the DAG

The Python scripts contain the various components needed for the simulation environment.

Run _python3 Sim_basic.py_ to generate the simulated graph. _Sim_corrupted.py_ contains the possibility of including corrupted behaviors. Set the malicious percentage and the number of peers/nodes/rounds inside the script.
